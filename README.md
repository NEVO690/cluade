# RAILBLAZE: City Run

An original endless-runner written in Python with **pygame-ce**. You sprint down
an endless procedurally generated city on three rail lanes, dodge trains, cars and
barriers, grab coins and power-ups, unlock characters, boards and cosmetics, finish
missions, level up and take part in seasonal events.

Everything (characters, city, music, sound effects, icons) is generated by the
game itself. There are no assets from other games and **no real-money purchases**.

---

## 1. Requirements

| What | Version |
|------|---------|
| Python | **3.9 – 3.13** (64-bit recommended) |
| pygame-ce | 2.4 or newer |
| numpy | 1.24 or newer (used to synthesise music; the game runs without it, just without music) |

Tested on Windows 10/11 and Linux.

## 2. Install & run

### Windows (recommended way)

1. Install Python from <https://www.python.org/downloads/> and tick **"Add python.exe to PATH"**.
2. Double-click **`install.bat`** (creates a virtual environment and installs the packages).
3. Double-click **`run_game.bat`**.

### Any OS, manually

```bash
python -m venv .venv
# Windows:  .venv\Scripts\activate      Linux/macOS:  source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

> If you have the old `pygame` package installed, uninstall it first
> (`pip uninstall pygame`) – `pygame-ce` replaces it and both use `import pygame`.

The first start takes a few seconds while the soundtrack is synthesised; it is
cached in `cache/music/` so later starts are instant.

## 3. Controls

| Action | Keyboard | Touch / mouse |
|--------|----------|---------------|
| Move left / right | `A` / `D` or `←` / `→` | swipe left / right |
| Jump | `W`, `↑` or `Space` | swipe up |
| Slide / roll (fast-fall in the air) | `S` or `↓` | swipe down |
| Ride a board (uses a Board Charge) | `B` | double-tap |
| Head Start / Score Booster (first seconds of a run) | `H` / `M` | tap the on-screen buttons |
| Pause | `Esc` or `P` | pause button (top right) |
| Debug overlay (FPS, speed, chunk, position, zone) | `F3` | – |

All keys can be re-bound in **Settings → Controls**.

## 4. Features

* **Endless 3D-style city** rendered with a custom depth-sorted perspective renderer:
  3 lanes, rails and sleepers, buildings with windows, street lamps, trees,
  billboards, neon signs, tunnels, bridges, signal gantries and metro stations.
* **7 city zones** with their own colours, buildings, obstacle styles, lighting
  and music: Downtown, Metro Station, Old Town, Industrial District, Harbor,
  Neon District, Skyline District. Zones blend smoothly into each other and new
  ones unlock with your level.
* **Obstacles**: low barriers (jump), high barriers (slide), blocks (change lane),
  parked & oncoming trains, ramps up onto train roofs, parked & moving cars.
  A *safe-lane* generator guarantees there is always a way through.
* **Difficulty scaling**: speed ramps from 15 m/s to 33 m/s, rows get denser and
  oncoming trains/cars appear as the distance grows.
* **Scoring**: distance points × multiplier (level bonus × combo × power-ups),
  coins, gems, a combo meter (coins, jumps over obstacles, roof landings, near misses).
* **6 power-ups**: Coin Magnet, Jet Boost, Shield, Score Multiplier, Super Jump,
  Speed Boost – each with icon, effect, timer, sound and particles.
* **Low-poly 3D characters**: every runner is a real 3D mesh (head, face, hair,
  backpack, limbs, shoes, accessories) on an animated skeleton – run, jump, slide,
  fall, idle, wave and cheer – lit and rendered in perspective in the game and on
  rotating turntables in the menus.
* **14 characters** with unique abilities (coin bonus, higher jumps, longer
  power-ups, score bonus, start magnet, start shield, XP bonus), bought with coins,
  gems, **Halloween Candy** (Vex, the pumpkin-headed prankster) or earned in the
  Season Pass (Kira).
* **Season Pass**: a 30-day season with a live countdown and 30 tiers. The free
  track gives coins and the exclusive *Nightfall Board* at tier 30; the premium
  track (10,000 coins – no real money) gives the exclusive character *Kira* at tier 1
  and more coins than the free track on every other tier. Season points come from
  distance, coins and missions. Exclusive rewards cannot be bought anywhere else.
* **Detailed world models**: multi-carriage trains with roofs, doors, windows,
  destination signs and hazard skirts; cars with wheels, glass cabins and lights;
  buildings with shop windows, striped awnings and roof ledges.
* **Boards** (Street, Neon, Hover, Cyber + event boards) – each with a look and a perk;
  a board absorbs one crash.
* **Locker**: choose, buy and equip everything you can own – Characters (3D
  turntable), Boards, Trails and Cosmetics (outfits, pickup effects, emotes).
* **Shop**: limited-time **Offers**, consumable Power-Ups and Upgrades.
* **Limited-time offers** (`data/offers.json`): a 3-day countdown starts the first
  time you play this version; when it hits zero the offers disappear. Current offers:
  *Vex for 900 coins* (instead of 150 Candy in the Locker) and a *Level 15 Boost* for
  50 gems (jumps you to level 15, unlocking every character up to level 15 and
  granting all level rewards on the way). Each offer can be bought once.
* **Upgrades**: 5 levels for Magnet, Jet Boost, Shield, Multiplier and Super Jump.
* **Missions**: 24 sequential missions (3 active at a time), 3 daily missions
  (new set every day) and event missions.
* **Progression**: XP and levels 1-50 with level rewards (coins, gems, items, zones, characters).
* **Achievements**: 18 achievements (First Run, Coin Collector, Speed Demon,
  Long Runner, Power Master, Millionaire, City Explorer …).
* **Daily rewards**: a 7-day login calendar that restarts after day 7 (or if you miss a day).
* **Events**: date-based seasonal events (Halloween, Winter, Summer, City Festival)
  with a theme tint, decorations, weather, a special currency, missions and a reward track.
* **Save system**: automatic JSON saves with atomic writes; corrupted files are
  backed up and replaced instead of crashing.
* **Settings**: music/SFX volume, graphics quality (Low/Medium/High), windowed /
  fullscreen, VSync, FPS counter, swipe sensitivity, key bindings, reset progress.
* **Audio**: every sound effect and a music loop per zone are synthesised at start-up
  (crossfading when you change zone). Your own audio files override them.
* **Robustness**: missing/broken JSON, assets, sounds or saves never crash the
  game – defaults are used and a message is shown. Crashes are written to
  `logs/crash.log`; a normal log is in `logs/game.log`.

## 6. Extending the game

All content is data-driven. Edit the JSON files in `data/` and restart.

### Add a character

Append to `data/characters.json`:

```json
{
  "id": "lila", "name": "Lila", "description": "Rooftop gardener.",
  "price": 9000, "currency": "coins", "unlock_level": 9,
  "colors": {"skin": [230, 190, 150], "hair": [90, 50, 30], "shirt": [120, 200, 80],
             "pants": [50, 50, 70], "shoes": [255, 255, 255], "accent": [255, 200, 0]},
  "hair_style": "bun", "accessory": "headphones", "build": 0.95,
  "ability": {"type": "coin_bonus", "value": 0.1, "desc": "+10% coins"}
}
```

* `hair_style`: `spiky`, `short`, `long`, `bun`, `mohawk`, `bald`
* `accessory`: `cap`, `headphones`, `goggles`, `bandana`, `visor`, `pumpkin`, `none`
* `currency`: `coins`, `gems` or `event:<event id>` (pay with that event's currency, e.g. `event:halloween` = Candy)
* `"season_only": "<season id>"` makes a character (or item) a Season Pass exclusive that the shop never sells
* `ability.type`: `none`, `coin_bonus`, `jump_bonus`, `powerup_duration`, `score_bonus`,
  `magnet_start` (value = seconds), `shield_start`, `xp_bonus`
  (new types: handle them in `GameSession.__init__` / `finalize` in `game/gameplay.py`).
* **Sprite art (optional)**: put frames in `assets/images/characters/<id>/run_0.png, run_1.png …`
  (also `jump_N.png`, `slide_N.png`, `fall_N.png`). If frames exist they replace the procedural model.

### Add a power-up

1. Add an entry to `data/powerups.json`:
   ```json
   {"id": "freeze", "name": "Time Freeze", "effect": "freeze", "icon": "star",
    "color": [150, 220, 255], "desc": "Slows the world.", "spawn_weight": 2,
    "durations": [5, 6, 7, 8, 9, 10], "upgrade_costs": [600, 1400, 3000, 6000, 10000],
    "params": {"speed_mult": 0.6}}
   ```
2. If `effect` is new, add a class to `game/powerups.py`:
   ```python
   @register("freeze")
   class FreezeEffect(PowerUpEffect):
       def __init__(self, definition, duration):
           super().__init__(definition, duration)
           self.speed_mult = float(self.params.get("speed_mult", 0.6))
   ```
   Available modifiers: `magnet_radius`, `score_mult`, `jump_mult`, `speed_mult`,
   `invincible`, `flying`, `absorbs_hit`, plus hooks `on_start / on_update / on_end(session)`.
3. Optional icon: `assets/images/icons/<icon>.png`, optional sound: `assets/sounds/<sound>.wav`.

It automatically spawns in runs, shows a HUD timer and (if `upgrade_costs` is not empty)
appears in Upgrades.

### Add a mission

Regular missions are completed in order (3 active at a time). Append to `regular` in
`data/missions.json`:

```json
{"id": "m25", "desc": "Collect 10 gems", "stat": "gems", "mode": "total", "target": 10,
 "reward": {"coins": 1000, "gems": 2, "xp": 300}}
```

Daily missions are drawn from `daily_pool` (`{target}` in `desc` is replaced by one of `targets`).

* `mode`: `total` (accumulates across runs) or `run` (must happen in one run)
* `stat`: `coins`, `gems`, `tokens`, `distance`, `score`, `jumps`, `slides`, `jump_over`,
  `slide_under`, `lane_switches`, `trains_landed`, `powerups`, `powerup_<id>`,
  `boards_used`, `runs`, `combo`, `zone_<zone id>`
* `reward`: any of `coins`, `gems`, `xp`, `item` (an item id), `consumable` (`{"board_charge": 2}`)

### Add a zone

Append to `data/zones.json` (copy an existing zone as a template). Important keys:

* colours: `sky_top`, `sky_bottom`, `fog`, `ground`, `road`, `sidewalk`, `ties`, `rail`
* `buildings`: `palette`, `height`, `depth`, `width`, `style`
  (`office`, `tower`, `brick`, `house`, `warehouse`, `neon`, `container`), window colours
* `night` (lit windows + glows), `tunnels`, `stations`, `bridges`, `water` (`"left"`/`"right"`)
* `decor`: weights for `lamp`, `tree`, `billboard`, `bench`, `barrels`, `chimney`, `crane`,
  `bollard`, `neon_sign`
* `obstacles`: weights for `low`, `high`, `block`, `train`, `car`, `moving_train`, `moving_car`
* `obstacle_style`: one of the styles in `game/obstacles.py → STYLES` (add your own there)
* `skyline`: `towers`, `skyscrapers`, `domes`, `factories`, `cranes`, `neon`
* `music`: `tempo`, `root` (MIDI note), `scale` (`major`, `minor`, `dorian`, `phrygian`,
  `pentatonic`), `progression`, `style`, `lead` – or drop `assets/music/<zone id>.ogg`
* `unlock_level`: player level required before the zone appears in runs

### Add an event

Append to `data/events.json`:

```json
{
  "id": "spring", "name": "Spring Bloom", "desc": "Flowers everywhere!",
  "start": "03-20", "end": "04-10",
  "currency": {"name": "Petals", "color": [255, 150, 200], "spawn_chance": 0.35},
  "theme": {"tint": [255, 200, 230], "tint_strength": 0.12, "decor": "flags",
            "weather": "confetti", "banner": [255, 120, 180], "banner_2": [120, 60, 160]},
  "missions": [{"id": "sp1", "desc": "Collect 50 Petals", "stat": "tokens", "mode": "total",
                "target": 50, "reward": {"coins": 500}}],
  "rewards": [{"tokens": 40, "reward": {"coins": 800}}, {"tokens": 150, "reward": {"gems": 5}}]
}
```

* Dates are `MM-DD` and may wrap over new year (`"12-10"` → `"01-15"`).
* `theme.decor`: `pumpkin`, `snowman`, `umbrella`, `flags`; `theme.weather`: `leaves`, `snow`, `confetti`, `sun`.
* Event-exclusive items: add `"event_only": "<event id>"` to an item in `items.json` and use it
  as a reward (`{"item": "..."}`); they are hidden from the shop until earned.
* To test an event outside its dates set `"force_event": "spring"` in `saves/settings.json`.

### Add a Season Pass season

Append a season to `data/season.json` (copy `s1`): `start` (YYYY-MM-DD), `days` (length;
the in-game countdown runs to the end), `premium_price`, `points_per_tier`, the point values
(`per_meter`, `per_coin`, `per_mission`, `per_run`) and `tiers` – each tier has a `free` and a
`premium` reward (`coins`, `gems`, `item`, `consumable`). Exclusive rewards are items or
characters marked `"season_only": "<season id>"`. When a season ends nothing more can be earned
or claimed; the next season in the file starts automatically on its start date.

### Add a limited-time offer

Add an entry to `data/offers.json` (`type` `item` with an `item` id, or `type` `level` with a
target `level`; plus `price`, `currency`, `title`, `desc`). `duration_days` sets how long the
offer window stays open after the first launch.

### Add shop items / cosmetics

Add entries to the lists in `data/items.json` (`boards`, `outfits`, `trails`, `effects`,
`emotes`, `consumables`). Boards support perks `none`, `coin_bonus`, `jump_bonus`,
`score_bonus`, `magnet`; trails styles `sparks`, `bubbles`, `streak`, `rainbow`, `stars`,
`leaves`; pickup effects `sparkle`, `burst`, `ring`, `confetti`.

### Replace placeholder art / audio / font

| Put this file | to replace |
|---|---|
| `assets/fonts/main.ttf` | UI font |
| `assets/images/icons/<name>.png` | any icon (`coin`, `gem`, `magnet`, `jet`, `shield`, `board` …) |
| `assets/images/characters/<id>/<pose>_<n>.png` | the procedural runner |
| `assets/sounds/<name>.wav/.ogg` | a sound effect (`jump`, `coin`, `hit`, `powerup`, `button`, `game_over` …) |
| `assets/music/<zone id or menu>.ogg/.wav` | a music loop |

## 8. Performance notes

* World streaming in 40 m chunks; chunks behind the camera are dropped immediately.
* Pooled particles with a per-quality cap; cached text, icons, glows and scaled sprites.
* Polygons far outside the screen are clipped before rasterising (huge speed-up for
  geometry next to the camera).
* Fixed 120 Hz physics sub-steps → no tunnelling through obstacles at high speed.
* If the game runs slowly, choose **Settings → Graphics Quality → Low**
  (shorter draw distance, no window detail, fewer particles).

## 9. Known limitations / ideas for extension

* The renderer is a custom pseudo-3D painter's-algorithm renderer on top of pygame
  (no GPU 3D); very long objects can occasionally overlap incorrectly for a frame.
  A port to Panda3D/Ursina could reuse `world.py`, `gameplay.py` and all systems unchanged
  and only replace `render.py`/`scenery.py`/drawing code.
* Characters and props are built in code as low-poly meshes (no Blender files needed).
  Sprite frames can still replace the 3D model per character (see above).
* Touch input uses SDL's mouse emulation, which works on Windows touch screens.
