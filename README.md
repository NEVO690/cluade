# TAF – מוד ל-Geometry Dash

מוד Geode ל-Geometry Dash (גרסה 2.2091) בהשראת הסרטון TAF (The Aura Farmer).

## מה יש במוד
- כפתור **TAF** בתפריט הראשי של המשחק.
- מסך TAF עם במה, עיר ברקע ושתי דמויות: **Aura Farmer** ו-**Larper Larry**.
- דמויות עם אנימציה: נשימה, מצמוץ, פה שזז כשהדמות מדברת, ותגובות (כעס, מכה, צחוק, אאורה, התקפה, הפתעה, שמחה).
- דיאלוג עם כתוביות מסונכרנות לקול, כולל **תמיכה בעברית**.
- כפתורים: הקודם, נגן/השהה, הבא, ניגון השורה מחדש, ניגון הסצנה מההתחלה.
- הגדרות: הפעלה וכיבוי של המוד, כתוביות (הצגה, למעלה או למטה, גודל, אותיות גדולות), עוצמת קול, מעבר אוטומטי לשורה הבאה.

## עריכת הדיאלוג
1. במשחק: TAF ← ⚙️ ← **All Settings**. אפשר גם לפתוח ישירות את התיקייה:
   `%LOCALAPPDATA%\GeometryDash\geode\config\nevo690.taf\`
2. מעתיקים לשם את הקובץ `dialogue.json` (נמצא בתיקייה `resources` בריפו) ועורכים אותו ב-Notepad.
3. כל שורה בקובץ נראית ככה:
   ```json
   { "speaker": "aura", "emotion": "aura", "listener": "neutral",
     "text": "הטקסט שנאמר", "audio": "line01.ogg" }
   ```
   - `speaker`: מי מדבר. `aura` או `larry`.
   - `emotion`: מה הדובר עושה. `neutral`, `happy`, `angry`, `hit`, `laugh`, `aura`, `attack` או `surprised`.
   - `listener`: איך הדמות השנייה מגיבה (אותן אפשרויות).
   - `cues` (לא חובה): פיצול של שורה ארוכה לכמה כתוביות לפי זמן בשניות.
4. במשחק לוחצים ⚙️ ← **Reload** והשינויים נטענים.

## הוספת קול
- שמים קבצי `ogg`, `mp3` או `wav` בתיקייה `audio`. מגיעים אליה מהכפתור **Audio Folder** בהגדרות.
- שם הקובץ צריך להיות בדיוק כמו שכתוב ב-`"audio"` בשורה.
- שורה בלי קובץ קול תוצג עם כתוביות בלבד, בזמן שמחושב לפי אורך הטקסט.

## החלפת הציורים
כל חלק בגוף של דמות הוא קובץ PNG נפרד בתיקייה `resources/sprites`. חלקים שמתחילים ב-`af_` שייכים ל-Aura Farmer, וחלקים שמתחילים ב-`ck_` שייכים לתרנגול. כדי להחליף ציור, מציירים קובץ חדש עם אותו שם (4 פיקסלים לכל יחידה במשחק) ובונים את המוד מחדש. אם הפרופורציות משתנות, מעדכנים את המיקומים ב-`resources/rig.json`.

## בנייה
GitHub Actions בונה את המוד אוטומטית בכל דחיפה לענף `taf-mod`. הקובץ המוכן (`.geode`) נמצא תחת Actions ← הריצה האחרונה ← Artifacts.
